# AI Arena · инструкция с защитой доступа

Инструкция по работе с AI Arena (Agent Mode) в виде защищённого веб-приложения:
**страницы зашифрованы**, выдаются только после проверки логина и пароля на сервере
защиты, счётчик просмотров ведёт сервер (сброс кеша и «другое устройство» его не
обнуляют), печать/копирование/сохранение запрещены.

Полное руководство по настройке: **[docs/ЗАЩИТА.md](docs/ЗАЩИТА.md)**

## Что внутри

| Путь | Назначение | Публичный? |
|------|------------|-----------|
| `index.html`, `app/` | приложение-просмотрщик (без паролей и без страниц) | да |
| `content/content.bin` | страницы инструкции, AES-256-GCM | да, но расшифровываются только с ключом пользователя |
| `auth/users.json` | логины, соль, PBKDF2-проверка, завёрнутый ключ контента | да, паролей в файле нет |
| `Arena_Instruction_App.html` | тот же просмотрщик одним файлом (для письма/флешки) | да |
| `server/` | серверы защиты: `local_server.py`, `deno.js`, `worker.js`, `node.js` | да |
| `arena_manual/` | скрипты автора: генерация доступов, сборка PDF/презентации | да |
| `protected/*.enc` | PDF/PPTX/XLSX автора, зашифрованы паролем владельца | да, но зашифрованы |
| `private/` | пароли, таблица выдачи, исходные страницы, архивы | **нет, не публикуется** |

## Быстрый старт (проверить локально)

```bash
python3 server/local_server.py          # http://127.0.0.1:8000
```
Откройте http://127.0.0.1:8000 — вход `developer` и пароль владельца
(см. `private/owner_pass.txt`) либо логин `user001` и его пароль из
`private/Таблица_логинов_и_паролей.xlsx`.

## Сборка защищённой части (автору)

```bash
pip install cryptography openpyxl
python3 arena_manual/gen_users.py        # сгенерировать/обновить 100 доступов
python3 arena_manual/build_secure.py     # собрать content/content.bin + auth/users.json
python3 arena_manual/build_secure.py --check   # проверить, что всё расшифровывается
python3 tools/make_single_file.py        # собрать Arena_Instruction_App.html
python3 tools/check_repo.py              # убедиться, что в публичную часть не утекли пароли
```

## Раздача пользователям

Отправляйте человеку **только его логин, пароль и ссылку** на приложение
(GitHub Pages / свой сервер). Никогда не пересылайте `private/` и таблицу целиком.

## Защита через GitHub

* приложение и зашифрованный контент раздаются с **GitHub Pages** (бесплатно);
* сервер проверки пароля и счётчика — Deno Deploy (вход через GitHub, бесплатно),
  Cloudflare Workers или ваш собственный сервер;
* ветку `main` закрывают правилом branch protection (инструкция и команды —
  `tools/protect_branch.sh`, `docs/ЗАЩИТА.md`);
* при каждом push GitHub Actions запускает `tools/check_repo.py` — страж не даст
  закоммитить пароли или открытые страницы.
